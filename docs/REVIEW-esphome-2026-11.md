# ESPHome-style review, 2026-11-23 — findings ledger

A review of every component against ESPHome's own review rules, so the gap to
upstream quality is a list instead of a feeling. Reviewed at `2c8c28b`
(esphome pinned 2026.11.0), with the prompts upstream dev `da0986ee94` uses on
its own PRs: `.agents/skills/code-review`, `silent-failure-review`, the detail
skills they cite, and `AGENTS.md`. Codex reviewed one component group per run
(read-only); four independent Claude agents then checked every blocker against
the code and its callers. Verdicts on the rows checked: 53 confirmed, 24
partial, 25 style, 0 refuted.

**Status** is `fixed #PR` (merged; bench-pending until the P9 run in
[`PLAN-esphome-quality.md`](PLAN-esphome-quality.md)) or `open`. Close a row by
editing its status in the PR that fixes it. Line numbers are as reviewed at
`2c8c28b` and drift; the finding text is what to search for. IDs (`uds#4`,
`cg#8`, …) are the ones PRs and commit messages cite.

**sev** is the reviewer's: `blocker` would stop an upstream PR, `should` is a
requested change, `nit` is optional. A "blocker" here is often a convention
(`CONF_` redefinition, schema extraction), not a bug; the functional bugs are
summarised in [`HANDOVER.md`](HANDOVER.md) §1.9.

## What the review taught

1. Bugs live in the glue, not the cores: setup ordering, subscription timing,
   task boundaries, stop/undo paths. Host tests covered `gateway_core.h`,
   `isotp_core.h`, the policies and the schemas, and no test ran component glue.
   Since #49–#53, `tests/host/test_glue_*.cpp` does, one binary each (see
   [`CONVENTIONS.md`](CONVENTIONS.md)).
2. A gate belongs at the send choke point, not at one entry point (`uds` read
   was gated, poll was not).
3. Schema bounds must match the C++ widths: `uint8_t` counts, payload lengths,
   millisecond timeouts at or above 2^31.
4. Never pass a pointer into an automation: `delay:` copies the pointer, not the
   data.
5. When a bug class is fixed once, sweep for its siblings (the `log_tap`
   receive gate missed statistics and `last_frame`).
6. Port the rest of upstream's `ci-custom` (`lint_conf_from_const_py` and
   friends) so convention drift fails CI instead of waiting for a review.
