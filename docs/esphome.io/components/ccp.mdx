The `ccp` component provides a CCP 2.1 client on a [CAN Gateway](/components/can_gateway/) port.
It supports ESP32 with ESP-IDF only; the gateway rejects ESP32-C5. Only one CCP hub may own a port.

## Passive Observation

Configure the referenced gateway port with `listen_only: true`, no routes and no cyclic sends.
Declaring a hub does not connect or poll automatically; the following example sends no commands.
All addresses and identifiers in these examples are fictional test values.

```yaml
ccp:
  id: calibration_hub
  can_gateway_id: observed_port
```

## Configuration variables

- **id** (**Required**, [ID](/guides/configuration-types/#id)): Hub identifier.
- **can_gateway_id** (**Required**, [ID](/guides/configuration-types/#id)): Gateway port, despite the option's hub-like
  name.
- **command_id** (*Optional*, int): 11-bit command identifier. Defaults to `0x700`.
- **response_id** (*Optional*, int): 11-bit response identifier. Defaults to `0x701`.
- **station_address** (*Optional*, int): 16-bit station address. Defaults to `0x0001`.
- **byte_order** (*Optional*, enum): Multi-byte command parameter order.
  - `little` *(default)*
  - `big`
- **response_timeout** (*Optional*, [Time](/guides/configuration-types/#time)): Command response timeout. Defaults to
  `100ms`.
- **allow_write** (*Optional*, boolean): Compile and permit the guarded write opcodes. Defaults to `false`.
  Memory and status reads still transmit when this is false. Calibration page selection requires `true`: it switches
  the calibration data page the ECU runs on, with ECU-defined effects, even though it writes no memory.
  `SET_S_STATUS` also requires `true`: it can request STORE (save calibration to non-volatile memory at shutdown)
  or RESUME (save DAQ setup at shutdown and restart DAQ after power-up).
  DAQ reads need `allow_write: true` because they configure DAQ with `WRITE_DAQ`; this requirement already existed.
  Gating the subsequent `SET_S_STATUS(0x82)` step therefore does not change measurement. DAQ start/stop remain ungated.
- **daq_anchor** (*Optional*, mapping): Known bytes checked to establish a DAQ result's identity.
  - **address** (**Required**, int): 32-bit anchor memory address.
  - **ext** (*Optional*, int): Address extension, 0–255. Defaults to `0`.
  - **expect** (**Required**, byte list): Expected bytes, length 1–7.
- **on_connected** (*Optional*, automation): Runs on successful connection.
- **on_response** (*Optional*, automation): Runs for a successful command response.
- **on_error** (*Optional*, automation): Runs on command failure.
- **on_daq** (*Optional*, automation): Runs for a DAQ data packet.
- **on_daq_read** (*Optional*, automation): Runs when a bounded DAQ collection finishes.
- All other options from [Component](/components/esphome/).

## Automations

### `on_connected` Trigger

Runs after connection; no callback arguments. The logging callback adds no commands.

```yaml
ccp:
  id: calibration_hub
  can_gateway_id: observed_port
  on_connected:
    then:
      - logger.log: "CCP event observed"
```

**Configuration variables:**

- **then** (**Required**, automation): Actions run for this event.

### `on_response` Trigger

Receives `command`, `return_code` and a byte vector `data`. The logging callback adds no commands.

```yaml
ccp:
  id: calibration_hub
  can_gateway_id: observed_port
  on_response:
    then:
      - logger.log: "CCP event observed"
```

**Configuration variables:**

- **then** (**Required**, automation): Actions run for this event.

### `on_error` Trigger

Receives `command` and `return_code`. The logging callback adds no commands.

### `on_daq` Trigger

### `ccp.select_cal_page` Action

Warning: this action transmits commands on the CAN bus.
Select a calibration page; requires `allow_write: true`. This switches the calibration data page the ECU runs on,
with ECU-defined effects. With `allow_write: false`, the action still validates and compiles, but is refused at runtime
with a warning and no command is sent. Commission a transmit-capable port before use.

```yaml
then:
  - ccp.select_cal_page:
      id: calibration_hub
```

**Configuration variables:**

- **id** (**Required**, [ID](/guides/configuration-types/#id)): CCP hub identifier.

### `ccp.daq_read` Action

Warning: this action transmits commands on the CAN bus.
Configure and collect a bounded DAQ burst. Requires `allow_write: true` because it configures DAQ with `WRITE_DAQ`;
this requirement already existed. With the default `require_anchor: true`, it also requires a configured `daq_anchor`.
The anchor bytes plus all field bytes must fit seven bytes.

```yaml
then:
  - ccp.daq_read:
      id: calibration_hub
      fields:
        - address: 0x1000
          size: 1
```

**Configuration variables:**

- **id** (**Required**, [ID](/guides/configuration-types/#id)): CCP hub identifier.
- **fields** (**Required**, list): Nonempty memory fields; combined size must fit one seven-byte ODT.
  - **address** (**Required**, int): 32-bit memory address.
  - **ext** (*Optional*, int): Address extension byte. Defaults to `0`.
  - **size** (**Required**, int): Field width, 1–7 bytes.
- **list** (*Optional*, templatable int): DAQ list number, 0–255. Defaults to `0`.
- **dto_id** (*Optional*, templatable int): 11-bit DAQ CAN identifier. Defaults to `0x702`.
- **event** (*Optional*, templatable int): Event channel byte. Defaults to `0`.
- **prescaler** (*Optional*, templatable int): Event prescaler, 0–65535. Defaults to `10`.
- **samples** (*Optional*, templatable int): Samples to collect, 1–65535. Defaults to `30`.
- **collect_timeout** (*Optional*, templatable int): Collection timeout in milliseconds, 1–4294967295.
  Defaults to `5000`.
- **require_anchor** (*Optional*, templatable boolean): Require the configured anchor to match. Defaults to `true`.

### `ccp.raw` Action

Warning: this action transmits commands on the CAN bus.
Submit a raw command payload. Write opcodes remain subject to the runtime write gate. Commission a transmit-capable port
before use.

```yaml
then:
  - ccp.raw:
      id: calibration_hub
      data: [0x1B, 0x02, 0x01]
```

**Configuration variables:**

- **id** (**Required**, [ID](/guides/configuration-types/#id)): CCP hub identifier.
- **data** (**Required**, templatable byte list): Raw command bytes; runtime accepts 1–8, zero-pads to eight and
  replaces the command counter byte.

### `ccp.set_enabled` Action

Warning: enabling this hub permits subsequent actions to transmit on the CAN bus.
Pause or resume command submission. Commission a transmit-capable port before use.

```yaml
then:
  - ccp.set_enabled:
      id: calibration_hub
      enabled: false
```

**Configuration variables:**

- **id** (**Required**, [ID](/guides/configuration-types/#id)): CCP hub identifier.
- **enabled** (**Required**, templatable boolean): Whether the hub accepts work.
