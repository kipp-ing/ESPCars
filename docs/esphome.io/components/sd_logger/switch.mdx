Requires [SD Logger](/components/sd_logger/) on ESP32-C6 with ESP-IDF 5.5 or later only. Other variants,
including ESP32-C5, are rejected. This debugging switch affects storage only and sends no vehicle-bus frames.

## Passive Logging

Leave the switch off to keep the writer draining normally.

```yaml
switch:
  - platform: sd_logger
    sd_logger_id: card_log
    name: "Freeze SD Writer"
    restore_mode: ALWAYS_OFF
```

## Configuration variables

- **sd_logger_id** (**Required**, [ID](/guides/configuration-types/#id)): Logger whose writer is frozen when the switch
  is on.
- **restore_mode** (*Optional*, enum): The writer always starts unfrozen at boot. Only `ALWAYS_OFF` is supported;
  modes that restore a saved value or start on are rejected. Equivalent `initial_state: OFF` /
  `restore_state: none` settings are accepted; other boot-state settings are rejected.
  - `ALWAYS_OFF` *(default)*
- All other options from [Switch](/components/switch/).

Freezing for longer than the RAM rings can absorb causes record loss; use this only for controlled diagnostics.
